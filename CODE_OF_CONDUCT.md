# Code of conduct

encoding3d is developed by several plant-modelling teams together. Everyone taking part (in issues, pull requests,
reviews, meetings) is expected to follow the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/):
be welcoming and respectful, give and accept constructive criticism, and focus on what is best for the community.

Unacceptable behaviour can be reported to the maintainers listed in `pyproject.toml`; reports are kept confidential.
