# fspm-TF

An exchange format for whole functional-structural plant model (FSPM) scenes, across platforms and languages
(openalea.metafspm, CPlantBox, GroIMP, VirtualPlantLab). It covers multiscale plant graphs, their state variables,
their geometry, and the environment's grids, in one glTF file per time step, with a shared vocabulary of variables.
It also aims to serve as an in-memory interface for coupling components across platforms.

Status: design phase. See the [design note](docs/design_note.md).
